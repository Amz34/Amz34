## 📐 How I work

1. **Measure first** — RSS, disk, latency, cost. No optimisation without a before number.
2. **Stay inside the free tier** — the free tier is the whole advantage.
3. **Make it recover itself** — watchdogs, health checks, idempotent scripts.
4. **Two languages** — the server speaks Python and bash; the client-facing layer stays simple.
